# Feature Specification: Базовая библиотека книг и загрузка файлов

**Feature Branch**: `001-book-library-upload`
**Created**: 2026-04-08
**Status**: Draft
**Input**: User description: "Реализовать базовую библиотеку книг и загрузку файлов. Приложение должно позволять пользователю загружать книги из файлов и ссылок на файлы в форматах .txt, .epub и fb2. Загруженные книги должны отображаться в виде списка или карточек в интерфейсе библиотеки, где для каждой книги видно её название, автора (если удалось извлечь из метаданных) и обложку (если есть). Книги должны сохраняться локально, чтобы список библиотеки сохранялся между сессиями. Пользователь видит список книг с возможностью: открыть для чтения, удалить, переименовать. Поиск по названию/автору."

## User Scenarios & Testing *(mandatory)*

### User Story 1 — Загрузка книг в библиотеку (Priority: P1)

Пользователь открывает веб-приложение в браузере и загружает одну или несколько книг, выбирая файлы с компьютера или указывая ссылки на файлы в форматах .txt, .epub и .fb2. После загрузки каждая книга появляется в библиотеке с извлечёнными метаданными: названием, автором (если удалось извлечь) и обложкой (если присутствует в файле).

**Why this priority**: Без загруженных книг библиотека пуста — это фундаментальная функция, без которой все остальные не имеют смысла.

**Independent Test**: Пользователь может загрузить хотя бы одну книгу и увидеть её в списке библиотеки с корректным названием.

**Acceptance Scenarios**:

1. **Given** библиотека пуста, **When** пользователь выбирает файл .epub с компьютера, **Then** книга появляется в списке с извлечённым названием и автором (если доступны).
2. **Given** пользователь на странице загрузки, **When** указывает корректную ссылку на файл .fb2, **Then** книга скачивается и добавляется в библиотеку.
3. **Given** пользователь выбирает файл неподдерживаемого формата (например, .pdf), **When** пытается загрузить, **Then** система отображает понятное сообщение об ошибке, книга не добавляется.

---

### User Story 2 — Просмотр и управление библиотекой (Priority: P2)

Пользователь видит список загруженных книг в виде карточек или списка. Для каждой книги отображаются название, автор и обложка. Пользователь может открыть книгу для чтения, удалить её из библиотеки или переименовать.

**Why this priority**: После загрузки книг пользователь должен иметь возможность просматривать их и управлять ими — это основной интерфейс взаимодействия с библиотекой.

**Independent Test**: При наличии хотя бы одной загруженной книги пользователь может увидеть её в списке, открыть для чтения и переименовать.

**Acceptance Scenarios**:

1. **Given** в библиотеке есть книги, **When** пользователь открывает страницу библиотеки, **Then** видит карточки книг с названием, автором и обложкой (если есть) и может переключиться на вид списка.
2. **Given** пользователь на странице библиотеки, **When** нажимает «Открыть» у книги, **Then** книга открывается в режиме чтения с динамической подгрузкой чанков по мере прокрутки.
3. **Given** пользователь на странице библиотеки, **When** переименовывает книгу, **Then** новое название сохраняется и отображается в списке.
4. **Given** пользователь на странице библиотеки, **When** удаляет книгу, **Then** книга исчезает из списка, запись удаляется из библиотеки, исходный файл на диске не затрагивается.

---

### User Story 3 — Поиск по библиотеке (Priority: P3)

Пользователь вводит поисковый запрос, и система фильтрует список книг по совпадению в названии или имени автора.

**Why this priority**: Поиск становится полезен при наличии достаточного количества книг в библиотеке. Не блокирует основную функциональность.

**Independent Test**: При наличии нескольких книг пользователь может ввести часть названия или имени автора и увидеть отфильтрованный список.

**Acceptance Scenarios**:

1. **Given** в библиотеке есть несколько книг, **When** пользователь вводит часть названия или имени автора, **Then** отображаются только книги, у которых название или автор содержат введённый текст.
2. **Given** в библиотеке есть книги, **When** пользователь вводит текст, не совпадающий ни с одной книгой, **Then** отображается сообщение «Ничего не найдено».
3. **Given** пользователь выполнил поиск, **When** очищает поисковую строку, **Then** отображается полный список книг.

---

### Edge Cases

- **Повреждённый файл**: При загрузке повреждённого файла .epub/.fb2/.txt загрузка отменяется, пользователю отображается сообщение о том, что файл повреждён.
- **Дубликат книги**: Если книга с таким же названием И автором (если автор извлечён; если нет — только по названию) уже есть в библиотеке, загрузка отменяется, пользователю отображается сообщение «Книга уже есть в библиотеке», интерфейс прокручивает список к этой книге.
- **Недоступная ссылка**: Если ссылка на файл недоступна или некорректна, загрузка отменяется, пользователю отображается сообщение об ошибке.
- **Большой файл**: Максимальный размер файла для загрузки — 50 МБ. При превышении лимита загрузка отменяется, пользователю отображается сообщение о превышении допустимого размера.
- **Отсутствие метаданных**: Если у книги нет метаданных, в качестве названия используется имя файла, поле автора остаётся пустым, вместо обложки отображается изображение-заглушка по умолчанию.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Система MUST позволять пользователю загружать книги из локальных файлов на компьютере.
- **FR-002**: Система MUST позволять пользователю загружать книги по ссылке на файл.
- **FR-003**: Система MUST поддерживать форматы файлов .txt, .epub и .fb2.
- **FR-004**: Система MUST извлекать метаданные книги (название, автор) из файла при загрузке.
- **FR-005**: Система MUST извлекать обложку книги из файла, если она присутствует.
- **FR-006**: Система MUST отображать список загруженных книг в виде карточек по умолчанию с возможностью переключения на вид списка.
- **FR-007**: Для каждой книги в списке MUST отображаться название, автор (если извлечён) и обложка (если есть).
- **FR-008**: Пользователь MUST иметь возможность открыть книгу для чтения. При загрузке книга разбивается на чанки. В режиме чтения на HTML-странице динамически подгружаются чанки, попадающие в область видимости, с запасом на предыдущие и следующие чанки. Невидимые чанки выгружаются из памяти. 
- **FR-009**: Пользователь MUST иметь возможность удалить книгу из библиотеки. Удаление книги из библиотеки не должно удалять исходный файл с диска.
- **FR-010**: Пользователь MUST иметь возможность переименовать книгу.
- **FR-011**: Система MUST позволять искать книги по названию и имени автора.
- **FR-012**: Система MUST сохранять список книг локально между сессиями.
- **FR-013**: Система MUST отображать понятное сообщение об ошибке при попытке загрузить файл неподдерживаемого формата.
- **FR-014**: Система MUST обрабатывать файлы без метаданных, используя имя файла как название книги по умолчанию.
- **FR-015**: Система MUST отменять загрузку и отображать сообщение об ошибке при попытке загрузить повреждённый файл.
- **FR-016**: Система MUST отменять загрузку дубликата книги (совпадение названия И автора; если автор не извлечён — только названия) и отображать сообщение «Книга уже есть в библиотеке», прокручивая список к существующей книге.
- **FR-017**: Система MUST ограничивать размер загружаемого файла 50 МБ и отображать сообщение о превышении лимита.

### Key Entities

- **Книга**: Представляет одну загруженную книгу. Атрибуты: уникальный идентификатор, название, автор (опционально), путь к файлу на диске, обложка (опционально, изображение), формат файла (.txt/.epub/.fb2), дата добавления, разбитый контент на чанки (для режима чтения).
- **Библиотека**: Коллекция всех загруженных книг пользователя. Отображается в виде списка или карточек с поддержкой поиска и фильтрации.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Пользователь может загрузить книгу из локального файла в формате .epub, .fb2 или .txt менее чем за 10 секунд (для файлов до 50 МБ).
- **SC-002**: Пользователь может загрузить книгу по ссылке на файл менее чем за 30 секунд (для файлов до 50 МБ при стабильном соединении).
- **SC-003**: Название и автор извлекаются из метаданных не менее чем в 90% корректных файлов .epub и .fb2.
- **SC-004**: Пользователь может найти нужную книгу по названию или автору с помощью поиска, получая релевантные результаты менее чем за 1 секунду.
- **SC-005**: Список библиотеки сохраняется и восстанавливается между перезапусками приложения без потери данных.
- **SC-006**: 95% пользователей успешно выполняют полный цикл: загрузка → просмотр в библиотеке → открытие для чтения — с первой попытки.

## Assumptions

- Веб-приложение работает локально на Windows 10 без необходимости подключения к интернету (кроме загрузки книг по ссылке).
- Пользователь — один человек, многопользовательский режим не предусмотрен.
- Чтение книги открывается в браузере (не во внешнем приложении).
- Файлы книг хранятся локально на диске пользователя в выделенной директории приложения.
- Обработка больших файлов (>100 МБ) не является приоритетом для первой версии, но система не должна падать.
- Для файлов .txt автор и обложка не извлекаются (формат не поддерживает метаданные) — используется имя файла как название.
- Ссылки на файлы — это прямые HTTP/HTTPS-ссылки на скачивание файла, не требующие авторизации.
